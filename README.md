# 数理投票 · 双色球 / 大乐透多学科选号

一个可以直接用手机流量打开、也可以「添加到主屏幕」的静态网页。

- **在线地址**：<https://xiaomayi1899.github.io/lucky-oracle/>
- **只做两个彩种**：双色球、大乐透
- **六大学科**：开奖走势学、概率学、统计学、心理学、博弈学、未来学
- **逐号投票**：每个公式独立打分，给最看好的号码投票，票数最高者组成推荐号码
- **两套公式完全隔离**：双色球 86 个公式，大乐透 87 个公式，互不共用
- **开奖后自动更新**：GitHub Actions 每 10 分钟抓取官方开奖数据并重新部署
- **零依赖**：纯静态 HTML / CSS / JavaScript，不需要服务器、数据库或构建工具

> **这不是预测。** 彩票每期开奖都是独立随机事件，任何走势、公式、学科都不能提高中奖概率。
> 本页只是把不同角度的统计描述放在一起投票，结果稳定可复现，但不代表更可能中奖。
> 理性购彩，量力而行，未满 18 周岁禁止购买彩票。

## 它是怎么算的

1. **两套公式，互不共用。**
   双色球用红球 1–33、蓝球 1–16 的一套；大乐透用前区 1–35、后区 1–12 的另一套。
   代码里按彩种前缀强制隔离（`ssq_` / `dlt_`），交叉注册会直接抛错，从机制上避免混用。

2. **每个公式独立打分。**
   每个公式对号码池里每个号码算一个分数，按该公式内部分数归一化，再给最看好的 3–4 个号码各投 1 票（权重默认 1，可由回测优化调整）。

3. **票数最高者入选。**
   汇总所有票数，红球/前区取票数最高的 6 个或 5 个，蓝球/后区取最高的 1 个或 2 个，即「最终一注」。
   票数相同时，按归一化总分排序。

4. **备选一注。**
   在候选池里枚举，找出与主推荐至少差 2 个号码、且组合总票数最大的那一组。

心理学与博弈学方向相反：心理学给「大众会偏爱」的号码高分，博弈学给「被分摊风险低」的号码高分。
两种观点在同一个投票池里竞争，页面会展示每个学科对最终号码贡献了多少票。

## 页面能看到什么

- 最新开奖、奖池滚存、下期开奖倒计时
- 最终一注与备选一注，每个球右上角标出得票数
- 号码投票条形图（主号区 / 特殊号区可切换）
- 六大学科手风琴：每个公式的名称、公式表达式、当前看好的号码
- 最近 30 期号码分布矩阵
- **公式权重优化**：用最近 100 期搜索每个公式的最佳权重（坐标上升 + 双折约束），
  再用更早的 50 期做独立验证。页面并排显示「训练集变化」和「独立验证变化」，
  如果训练集提升而验证集下降，会明确标成过拟合。
- **历史回测**：用当前权重回放最近 100 期，显示平均命中、最好成绩和每期明细，
  并给出「纯随机选号的期望命中」作对照。

> 实测结果：在双色球与大乐透上，100 期训练集可以做到 +10%～+34%，
> 但独立验证集反而下降 5%～6%。这说明权重优化只是拟合历史噪声，
> 不会提高未来中奖率。页面如实展示这两组数字，不做隐藏。

## 数据来源

- 中国福利彩票官方公开接口：<https://www.cwl.gov.cn/>（双色球）
- 中国体育彩票官方公开接口：<https://www.sporttery.cn/>（大乐透）
- 备用镜像：<https://datachart.500.com/>（GitHub Actions 海外服务器通常无法直连官方接口时自动回退）

`scripts/fetch_data.py` 只使用 Python 标准库，每 10 分钟运行一次：

1. 优先抓取官方接口，失败时回退到 500.com 公开历史页
2. 合并写入 `data/lottery.json`（保留最近 300 期）
3. 提交变更并触发 GitHub Pages 重新部署

单个来源失败时保留上一次成功抓取的数据，不会把页面清空。

## 本地运行

```bash
# 任意静态服务器都可以
python -m http.server 8000
# 然后打开 http://localhost:8000

# 手动更新数据
python scripts/fetch_data.py
```

2. 点底部「分享」→「添加到主屏幕」
3. 以后从桌面图标打开即为全屏页面，断网也能看缓存的开奖数据
